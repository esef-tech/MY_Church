# International Central Gospel Church (ICGC) Web Application
Built with **Vue 3** (Composition API) and **Tailwind CSS**. Cloned directly from https://centralgospel.com/.

## Features Included
- **Live Broadcast & Service Schedule**: Real-time service countdown, worship service video stream & audio feed.
- **Living Word Devotional**: Daily devotional reading by Pastor Mensa Otabil with embedded audio player, scriptures, confession, and prayer.
- **Sermons & Media Archive**: Video and audio sermon player, series categorization, and sermon study outlines.
- **Online Giving Portal**: Tithe, First Fruits, Offering, Central Aid, and Project giving with Mobile Money (MTN, Telecel, AT), Cards, and USSD (*714*33#).
- **Branch / Temple Locator**: Worldwide directory of ICGC assemblies across Ghana, UK, USA, Canada, and Africa with service times and directions.
- **Central Aid Educational Outreach**: Ghana's flagship scholarship initiative supporting over 52,000 students.
- **Prayer & Connect**: Pastoral prayer request submission and counseling contact.

## How to Run
1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```
Server runs at http://localhost:3000.

3. Build for production:
```bash
npm run build
```
